# Ragsss's Little World — Enchanted Birthday Surprise 🌸

A breathtaking, luxury interactive birthday surprise website designed with immense love, elegance, and magic for **Ragsss** by **Gokul Kumar**.

---

## 🌟 What's New in this Masterpiece Redesign

1. **Magical Celestial Entrance Portal (`index.html`)**:
   - Animated aurora glow, floating pastel petals, and sparkling stardust.
   - Interactive 4-capsule PIN entry that dynamically lights up the letters **R · A · G · S** with romantic gold sparks!
   - Built-in hint toggle (*Special date: 2811*).
   - Smooth opening transition into the main world.

2. **Luxury Single-Page Experience (`pages/home.html`)**:
   - **Floating Frosted Glass Sidebar**: With breathing avatar ring, live mini-music player widget, and elegant icons.
   - **Interactive Birthday Cake**: 3-tier SVG cake with animated flickering flames — click to blow candles & launch festive confetti!
   - **Live Friendship Counter**: Live ticker counting days, hours, minutes, and seconds since May 7, 2026, 7:30 AM.
   - **Vintage Parchment Birthday Wish**: Heartfelt Tamil/Tanglish birthday letter in vintage parchment paper styling.
   - **3D Wax-Sealed Personal Letter**: Enter secret key (`Rags`) to break the wax seal and reveal Gokul's private letter.
   - **Polaroid Memories Wall**: Authentic scrapbook polaroids with washi tape, memory date pills, tags, and fallback icons.
   - **Our Journey Roadmap**: Glowing vine roadmap tracking milestones from *Class Mate* to *My Everything*.
   - **Mood Magic Grid**: 6 interactive mood cards with 3D emojis and heartwarming cheer-up messages from Gokul.
   - **Enchanted Memory Jar**: 3D glass jar with floating stars that shakes playfully and dispenses folded memory notes.
   - **Virtual Gifts (Unwrap Me!)**: 6 luxury 3D gift boxes that pop open with confetti to reveal sweet presents.
   - **Integrated Music Player**: Featuring *Azhiyaadha Oviyam* with spinning vinyl disc, animated bouncing sound equalizer, and time scrubber.
   - **Spotify Playlist Embed**: Framed player for the shared Spotify playlist.
   - **Late Night Call Memories**: iOS/WhatsApp-style call memory cards with timestamps and duration pills.
   - **Memory Bot Companion**: Floating friendly chat buddy answering questions about the story, jokes, and memories.
   - **Secret Memories Vault**: Password-protected vault (`073101`) with secret letter and glowing nickname chips (*thangoooo, sweetheart, pattu, ammu, baby*).
   - **Grand Finale**: Handcrafted gold pledge card with celebratory fireworks confetti.

3. **100% Offline & `file://` Compatible**:
   - Zero network `fetch()` dependencies that trigger CORS errors on local file systems.
   - All data is bundled safely via `data/*.js` files.
